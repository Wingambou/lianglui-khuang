# LIANGLUI KHUANG

**Digital Song Book**

A simple and accessible digital song book for worship, personal devotion, and reflection.

## Overview

**LIANGLUI KHUANG** brings three song books together in a single digital application, providing a convenient way to browse, search, read, and save songs.

The application is designed with a clean and comfortable reading experience while preserving the character of a traditional song book.

## Features

* Three integrated song books
* Song search
* Favourite songs
* Song categories
* Adjustable reading settings
* Light and dark themes
* Song sharing
* Progressive Web App (PWA) support
* Mobile and desktop support
* Offline-capable application experience

## Song Books

The application currently contains:

* **Hiuna Khomlui**
* **Khristen Madui Lui**
* **Luisan**

The original song and lyrics collection is preserved without adding or removing songs.

## Live Application

Access the public version of LIANGLUI KHUANG:
